# Employee Management System

A full-stack CRUD application built with the MERN stack (MongoDB, Express, React, Node.js) for managing employee records. This project was built as an assessment test.

## Features
* **User Authentication:** JWT-based secure login.
* **CRUD Operations:** Create, Read, Update, and Delete employee records.
* **Search:** Filter the employee list by name dynamically.

## Tech Stack
* **Frontend:** React.js, HTML/CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB

## How to Run Locally

1. **Clone the repository:**
   \`\`\`bash
   git clone https://github.com/dnyaneshwar045/employee-management-system.git
   \`\`\`

2. **Setup the Backend:**
   * Open a terminal in the backend folder.
   * Run \`npm install\`
   * Create a \`.env\` file and add your \`MONGO_URI\` and \`JWT_SECRET\`.
   * Run \`npm start\`

3. **Setup the Frontend:**
   * Open a terminal in the frontend folder.
   * Run \`npm install\`
   * Run \`npm start\`
